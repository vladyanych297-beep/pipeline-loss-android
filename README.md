Android-калькулятор потерь давления в прямом трубопроводе. Android 8.0 и новее.

## Установка

[Скачать последнюю версию APK](https://github.com/vladyanych297-beep/pipeline-loss-android/releases/latest)

На странице релиза откройте файл `PipelineLoss-<версия>.apk`. Новые версии устанавливаются поверх прежней с сохранением настроек. Разрешайте установку только APK из этого репозитория, подписанного ESI.Company.

## Возможности

- Материал трубы, стандартная или собственная стенка, связанные диаметры.
- Скорость, расход в м³/ч и л/с, длина и температура воды.
- Заморозка входных параметров, автоматический подбор ближайшей большей трубы при замороженных длине и скорости.
- Потери в кгс/см² и метрах, сопротивление в Па/(т/ч)².
- Начиная с версии 1.2.0 — проверка и скачивание обновлений при открытии приложения. Установку подтверждает системный установщик Android; при первом обновлении может потребоваться разрешение для этого приложения.

Для расчёта интернет не нужен. Он используется только для проверки и загрузки обновлений с GitHub. Расчётные данные и настройки на GitHub не отправляются.

## Файлы релиза

- Подписанный установочный APK.
- SHA-256 установочного файла.
- `update.json`: имя пакета, номер версии, ссылка APK, размер и SHA-256.
- Отметка авторских прав ESI.Company.

Приложение проверяет SHA-256, пакет `ru.pipeline.loss`, увеличение номера версии и совпадение подписи с установленным приложением. APK с другой подписью или повреждённый файл отклоняются.

Постоянный адрес метаданных: [update.json](https://github.com/vladyanych297-beep/pipeline-loss-android/releases/latest/download/update.json).

В репозитории публикуются установочные файлы и описание. Приватный ключ подписи и пользовательские настройки не публикуются.
